# Шрифты

## OpenDyslexic 0.940

Гарнитура для инструмента «Шрифт для дислексии». Буквы имеют утяжелённый низ
и намеренно несимметричные формы: `b`/`d`, `p`/`q`, `n`/`u` перестают быть
зеркальными отражениями друг друга, и их труднее перепутать.

* Автор: Abbie Gonzalez, <https://abbiecod.es>
* Версия: 0.940 (2019)
* Лицензия: **SIL Open Font License 1.1** — полный текст в [OFL.txt](OFL.txt)

Лицензия и сведения об авторстве взяты не со стороннего сайта, а из таблицы
`name` самих файлов шрифта (nameID 0, 13, 14), то есть относятся именно
к этим экземплярам.

### Что требует OFL при распространении

* Файлы шрифта передаются вместе с текстом лицензии — поэтому `OFL.txt`
  лежит рядом и не должен удаляться из пакета.
* «OpenDyslexic» — **Reserved Font Name**. Это ограничение на ИЗМЕНЁННЫЕ
  версии: если файлы будут отредактированы (подрезаны глифы, пересобраны
  в другой формат с правкой метаданных), результат придётся переименовать.
  Простая конвертация формата без правки таблицы `name` изменением не считается.
* Шрифт нельзя продавать сам по себе. В составе пакета он распространяется
  свободно.

### Покрытие символов

Проверено по таблице `cmap` файлов:

* латиница ASCII — 58/58;
* кириллица `U+0410-044F` — **64/64**, плюс `Ё` и `ё`;
* блок `U+0400-04FF` целиком — 213/256 (не хватает нерусских служебных знаков
  и части букв других славянских языков);
* всего 1614 кодовых точек.

Для русского текста шрифт годится полностью — запасные варианты в стеке
`font-family` нужны только на случай, если файл не доехал.

### Формат

Здесь `.otf`, потому что в таком виде шрифт распространяет автор.

`.woff2` весит примерно втрое меньше и поддерживается всеми актуальными
браузерами. Если понадобится ужать (около 888 КБ → около 300 КБ), конвертация
делается без потери качества:

```
npx woff2 OpenDyslexic-Regular.otf
```

или через `fonttools`:

```
pyftsubset OpenDyslexic-Regular.otf --flavor=woff2 --output-file=OpenDyslexic-Regular.woff2 \
  --unicodes="U+0000-00FF,U+0400-04FF"
```

Второй вариант заодно оставляет только латиницу и кириллицу. После конвертации
нужно поправить `src` и `format()` в `@font-face` (файл `assets/src/css/panel.css`)
и добавить `.woff2` в `loader` сборки (`assets/esbuild.config.js`).

Пока этого не сделано, цена не так велика, как кажется: `@font-face` ленив,
и файлы скачиваются только у тех, кто включил этот шрифт в панели.
